# entities-ink-bullet-train

A dice-driven interactive story about a sleeper-train journey, written as an ink script, with a storyboard of its opening.

## What it is for

The script holds a game-jam design: a character with five attributes rolls dice against tasks, sleeping restores the dice, and health falls as they run out. The storyboard and its PDF export sketch the first scene.

## Build and run

Open `bullet-train-jam.ink` in an ink editor and play it.
